# 海卓大脑 H5 小程序联调包

此包用于满天星小程序的 WebView 联调。启动后可体验自动登录、文字对话、历史搜索、会议预约及确认。登录账号、消息和会议结果均为模拟数据。演示记录保存在服务进程内，重启后重置。

## 运行和部署

1. 解压交付包，在解压目录用 Node.js 24 运行 `node server.mjs`。交付包已包含构建产物，无需安装 npm 依赖。
2. 本地浏览器访问 `http://127.0.0.1:8080/__h5-demo`。需要调整监听地址或端口时，设置环境变量 `HOST` 和 `PORT`。
3. 在联调环境部署同一个 Node 服务，将联调 HTTPS 域名的根路径反向代理到它。请保持页面和 `/api/`、`/agui/` 同源，并关闭 SSE 响应的代理缓冲。这个版本需要同时部署 `server.mjs`、`mock.mjs` 和 `public/`。

## 满天星小程序接入

1. 将 `miniprogram/pages/haizhuo-h5/` 复制到小程序的页面目录，并在 `app.json` 的 `pages` 中注册 `pages/haizhuo-h5/index`。
2. 修改页面 `index.js` 中的 `h5Url`，填入实际联调地址 `https://<联调域名>/__h5-demo`。在小程序后台将该 HTTPS 域名配置为 WebView 业务域名。
3. 在满天星对应入口的点击事件中打开此页面。

```js
wx.navigateTo({ url: "/pages/haizhuo-h5/index" });
```

每次从小程序打开该入口，演示服务会生成一次性票据，H5 自动完成登录。验收时可用真机检查文字发送、历史切换、会议确认，以及退出后从小程序重新进入。

满天星真实票据签发和核销的提议接口见随包的《登录对接契约》。当前交付包用于 Mock 联调。正式接入需要双方确认接口，再替换演示登录和业务数据。
