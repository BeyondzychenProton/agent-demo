# 海卓大脑 × 满天星组织通讯录对接文档

接口版本 v1 ｜ 2026-11-17

## 1. 对接范围

满天星将部门和用户数据主动推送到海卓大脑。首次分批推送全量数据，之后推送新增、修改、停用、删除和恢复。部门来源为 `sys_dept` 中 `type=0` 的记录，用户来源为 `sys_user`。请按下文字段组装请求，源密码、证件、薪酬等字段留在满天星。

海卓大脑使用用户手机号创建登录账号。用户首次使用初始密码登录时需先改密。后续推送会同步姓名、手机号和账号状态，并保留用户已设置的密码。

## 2. 接口和鉴权

| 项目 | 约定 |
| --- | --- |
| 请求方法与路径 | `POST /api/integrations/mantianxing/v1/directory/changes` |
| 联调及生产域名 | 由海卓大脑项目方分别提供 |
| 传输 | HTTPS，JSON 请求体，UTF-8 编码 |
| 请求头 | `Content-Type: application/json` |
| 服务鉴权 | `X-MTX-Sync-Token: <双方约定的令牌>` |

海卓大脑提供各环境的令牌，经双方约定的安全渠道交付。满天星在服务端保存令牌，每次请求通过上述请求头传递。HTTPS 负责传输加密，接口直接接收 JSON。

## 3. 请求字段

顶层包含 `departments` 和 `users` 两个数组。可只传其中一个，单批合计 **1–500 条**。主键 ID 和 `version` 使用正的 64 位整数，建议在 JSON 中用十进制字符串传输，尤其是超过 JavaScript 安全整数范围的值。

### 部门 `departments[]`

| 请求字段 | 来源 | 新增、更新或恢复时的要求 |
| --- | --- | --- |
| `deptId` | `sys_dept.dept_id` | 必填，部门的稳定 ID |
| `parentId` | `sys_dept.parent_id` | 可空。根部门传 `null` 或 `"0"`，父部门不能是自身 |
| `deptName` | `sys_dept.dept_name` | 必填，非空，最多 30 字符 |
| `orderNum` | `sys_dept.order_num` | 可省略，整数，默认 0 |
| `status` | `sys_dept.status` | 必填，`"0"` 启用、`"1"` 停用 |
| `delFlag` | `sys_dept.del_flag` | 必填，存续传 `"0"`，删除传 `"2"` |
| `version` | 满天星生成 | 必填，每次变更递增 |

### 用户 `users[]`

| 请求字段 | 来源 | 新增、更新或恢复时的要求 |
| --- | --- | --- |
| `userId` | `sys_user.user_id` | 必填，用户的稳定 ID |
| `deptId` | `sys_user.dept_id` | 可空。未分配部门传 `null` 或 `"0"` |
| `userName` | `sys_user.user_name` | 必填，非空，最多 50 字符 |
| `nickName` | `sys_user.nick_name` | 必填，非空，最多 50 字符。源值为空时可用 `user_name` 补齐 |
| `email` | `sys_user.email` | 可空，最多 50 字符 |
| `phonenumber` | `sys_user.phonenumber` | 必填，用于海卓大脑登录。7–20 位数字，可带前导 `+` |
| `status` | `sys_user.status` | 必填，`"0"` 启用、`"1"` 停用 |
| `delFlag` | `sys_user.del_flag` | 必填，存续传 `"0"`，删除传 `"2"` |
| `version` | 满天星生成 | 必填，每次变更递增 |

删除记录只需对应的 ID、`version` 和 `delFlag="2"`。其他状态值和空值的业务映射请在联调前确认。

## 4. 变更、版本与重试

| 事件 | 满天星发送 | 海卓大脑处理 |
| --- | --- | --- |
| 新增 | 新 ID、完整记录、`delFlag="0"` | 新建部门或用户。同步用户时创建登录账号 |
| 修改 | 原 ID、更高版本、变更后的完整记录 | 更新名称、归属、手机号等字段 |
| 停用 | 原 ID、更高版本、完整记录、`status="1"` | 保留记录并标记停用。停用用户会禁用登录并撤销已有会话 |
| 删除 | 原 ID、更高版本、`delFlag="2"` | 隐藏删除记录并保留删除版本。用户登录同时禁用 |
| 恢复 | 原 ID、更高版本、完整记录、`delFlag="0"` | 恢复记录。恢复为启用时发送 `status="0"` |

- 同一来源 ID 的版本在每次变更时严格递增，部门与用户各自计版本。可使用满天星持久化事件序号。秒级 `update_time` 可能重复或为空，不能直接作为版本。
- 同一事件重试沿用原版本和原请求内容。同版本和更旧版本返回 `204`，记录保持当前状态。收到删除后，迟到的旧更新也不会恢复该记录。
- 删除部门只影响该部门。子部门及用户的删除或迁移由满天星分别通知。已同步的部门如果变为 `type=1` 岗位节点，请发送该部门的删除记录。
- 首次全量和后续增量共用这个接口。请保留全量基线之后产生的变更，使增量版本高于对应基线版本。未出现在批次中的 ID 保持原状态。部门和用户可以跨批次到达，建议先推部门再推用户，方便核对归属。

## 5. 请求示例

新增一个部门和一名用户的请求体，可保存为 `directory-push.json`。

```json
{
  "departments": [
    {
      "deptId": "200",
      "parentId": null,
      "deptName": "联调部门",
      "orderNum": 10,
      "status": "0",
      "delFlag": "0",
      "version": "1"
    }
  ],
  "users": [
    {
      "userId": "9007199254740993",
      "deptId": "200",
      "userName": "integration-test",
      "nickName": "联调用户",
      "email": "integration-test@example.com",
      "phonenumber": "19900000301",
      "status": "0",
      "delFlag": "0",
      "version": "1"
    }
  ]
}
```

联调调用示例。运行前设置 `HZ_BASE_URL` 为海卓大脑提供的 HTTPS 地址，将约定令牌注入运行环境中的 `MTX_SYNC_TOKEN`。

```bash
curl -i -X POST "${HZ_BASE_URL}/api/integrations/mantianxing/v1/directory/changes" \
  -H 'Content-Type: application/json' \
  -H "X-MTX-Sync-Token: ${MTX_SYNC_TOKEN}" \
  --data-binary @directory-push.json
```

删除该用户的最小请求体。

```json
{
  "users": [
    {
      "userId": "9007199254740993",
      "delFlag": "2",
      "version": "2"
    }
  ]
}
```

## 6. 返回与失败处理

同批数据在一个事务内处理。以 HTTP 状态码作为处理结果。

| HTTP 状态 | 含义 | 满天星处理 |
| --- | --- | --- |
| `204 No Content` | 批次已处理，包括已应用或因版本旧而忽略的记录。响应体为空 | 标记投递完成 |
| `400 Bad Request` | 请求体或必填字段无效 | 修正请求后重新投递 |
| `401 Unauthorized` | 令牌缺失或不匹配 | 核对目标环境和令牌配置 |
| `409 Conflict` | 登录手机号已被其他活跃账号占用，或属于平台管理员保留手机号。整批回滚 | 与海卓大脑确认冲突账号，解决后重新投递 |
| `415 Unsupported Media Type` | 请求 Content-Type 不匹配 | 改为 `application/json` |
| `503 Service Unavailable` | 同步接口未启用，或环境暂时不可用 | 确认服务状态，恢复后重试 |

超时、连接中断或其他临时服务端错误，保留原请求和版本，按退避策略重试。联调排查时提供请求时间、HTTP 状态、记录 ID 和版本，令牌请勿写入日志或排查材料。

## 7. 联调验收

| 用例 | 预期结果 |
| --- | --- |
| 创建测试部门和用户 | 返回 `204`，海卓大脑管理页显示对应部门和用户 |
| 修改用户部门与手机号 | 较高版本生效。用户可用新手机号和已设置的密码登录 |
| 重复发送同版本，再发送更低版本 | 均返回 `204`，页面数据保持最新版本 |
| 停用、删除、恢复同一用户 | 停用后登录失效，删除后管理页隐藏，较高版本恢复后重新显示；启用后可重新登录 |
| 发送含手机号冲突的批次 | 返回 `409`，该批次里的其他变更也未生效 |
| 使用错误令牌投递 | 返回 `401`，数据未入库 |

联调开始前，双方确认各环境域名和令牌交付方式、满天星版本生成规则、历史空状态映射，以及首批全量的数据范围。
