# Skills 管理原型对齐（已确认）

2026-11-24 用户确认以下规则，覆盖 11-23 导入设计中不支持 Agent 固定版本的限制。

## 行为

- 四类标签：全部按 Skill 去重；启用/停用针对已有发布版；草稿包含任何有 DRAFT 的 Skill，与启停集合可以重叠。
- 草稿标签显示草稿资源检查，其他标签显示当前生效配置。首次发布前无启停开关，首次发布默认停用。
- 修改复用草稿或从明确的当前生效版本复制。保存草稿不改变发布版。
- 当前生效版本使用显式指针。旧技能以实际运行正文、资料、可见范围建立基线，不能猜测最近的历史版本就是生效版。
- 已有 Agent 固定基线版本。发布新版本不自动升级已有 Agent；Agent 管理可明确选择已发布版本。
- 全局停用覆盖所有固定版本，下一轮不加载；已开始轮次不主动中断，已建会议、历史、草稿及引用保留。MCP 工具权限独立。
- 列表顶部只保留刷新/导入，行内只保留启停/修改。根据用户页面批注，移除原型不存在的“更多”和“···”菜单，以及手动新增、迁移和删除的页面入口。
- 修改页分基本信息、资源绑定、调用结果、变更记录；展示生效配置和 Agent 引用。原包只读，调整导入方式走重新导入生成草稿。
- 尚无数据的调用指标、执行中数量和通用审计明确显示未接入，不展示虚构数据。

## 实施与验收

1. 手工应用 V13（不在应用启动自动建表）；迁移基线、填生效指针、固定缺失的 Agent 版本，事务内可重跑。
2. 聚合列表/分类计数/草稿与生效详情；持久化展示名；资源计数来自版本依赖而非 Agent 绑定或参考文件数。
3. 固定版本运行读取采用每轮不可变快照。验证发布 B 后旧引用仍加载 A，显式升级后新轮次加载 B，旧轮次仍 A；全局停用阻止新轮次加载任何固定版本。
4. 页面按原型恢复，草稿可刷新找回、未发布可见、停用确认可取消、资源页区分草稿与生效版、发布检查阻断仍在后端执行。
5. 后端相关回归、前端测试与构建、浏览器按真实接口验收；不提交或覆盖工作区已有未提交工作。
