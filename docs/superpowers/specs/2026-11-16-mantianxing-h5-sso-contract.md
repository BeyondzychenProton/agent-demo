# 满天星小程序接入海卓大脑 H5 登录契约

状态：提议稿，供满天星与海卓大脑团队确认。

用户从已登录的满天星小程序进入海卓大脑 H5。满天星签发短时一次性票据，海卓大脑服务端核销票据，用核销响应中的已验证手机号匹配已有账号，并为该账号建立海卓大脑会话。

## 1. 满天星签发票据

接口为 `POST /api/sso/haizhuo/tickets`，小程序使用现有的满天星登录凭证调用。满天星服务端从当前登录会话取得身份和已验证手机号。签发请求无需携带手机号或用户 ID。

成功返回 `200 OK`：

```json
{
  "ticket": "<opaque-ticket>",
  "expiresIn": 60
}
```

`expiresIn` 单位为秒，建议有效期 60 秒。票据为不可预测的不透明字符串，绑定已登录用户和海卓大脑接入方。签发与核销响应均设置 `Cache-Control: no-store`。

满天星小程序用以下地址打开 WebView，票据经 URL 编码后放在片段中：

```text
https://<海卓大脑H5域名>/?view=h5#ticket=<URL编码后的票据>
```

## 2. 海卓大脑 H5 提交票据

H5 读取片段后立即从当前地址移除票据，再同源调用海卓大脑的 `POST /api/auth/mantianxing/exchange`：

```json
{
  "ticket": "<opaque-ticket>"
}
```

每次带新票据进入 H5 时，优先完成票据兑换，再加载对话列表。这样在同一台设备切换满天星账号后，仍按本次进入时的认证结果打开对话。该请求限定同源 JSON POST，票据只保留在当前兑换请求所需的内存中。H5 在当前 WebView 的 `sessionStorage` 记录兑换尚未完成的标记，成功并确认当前用户后清除。无票据刷新时，只有当前页没有该标记才通过 `GET /api/auth/me` 恢复登录，避免失败后刷新误用上一个账号的 Cookie。

## 3. 海卓大脑服务端向满天星核销

接口为 `POST /api/sso/haizhuo/tickets/redeem`。海卓大脑服务端通过 HTTPS 调用。建议使用满天星颁发的接入方专用凭证，在 `Authorization: Bearer <service-credential>` 中传递。请求体与第 2 节相同。

满天星校验调用方、票据归属、有效期和未使用状态，并在同一原子操作中标记票据已使用。并发提交同一票据时最多一次得到成功响应。成功返回 `200 OK`：

```json
{
  "phone": "13800000000"
}
```

首期建议中国大陆手机号统一返回 11 位纯数字，海卓大脑已有账号也采用同一格式。海卓大脑按手机号匹配唯一有效账号，以现有 `app_user.id` 读取会话和历史。找不到账号或匹配不唯一时，显示账号未开通并联系管理员。开户继续走现有账号维护流程。

海卓大脑成功建立会话后返回 `204 No Content`，通过现有加密会话 Cookie 写入登录态，生产环境启用 `Secure`。H5 随后调用 `GET /api/auth/me` 读取当前用户，再进入对话。兑换成功后清除浏览器上一次的会话选择，按本次账号重新加载历史。

## 4. 失败处理

| 情况 | 满天星接口 | 海卓大脑兑换接口及页面处理 |
| --- | --- | --- |
| 满天星会话失效 | 签发返回 `401` | 小程序引导用户重新登录满天星 |
| 核销请求缺少或使用了错误的服务凭证 | 核销返回 `401` 或 `403` | 兑换返回 `503`，提示暂时无法登录 |
| 票据无效、过期或已用 | 核销统一返回 `400`，错误码 `invalid_ticket` | 兑换返回 `401`，提示从满天星重新打开页面 |
| 手机号没有对应的唯一有效账号 | 核销成功 | 兑换返回 `403`，提示联系管理员开通 |
| 核销超时或满天星暂不可用 | 超时或 `5xx` | 兑换返回 `503`，提示从满天星重新打开页面获取新票据 |

已有票据的兑换失败时，H5 留在登录失败页。本次入口只有兑换成功才进入对话。票据和服务凭证不写入访问日志或埋点。核销超时后使用新票据，因为原请求可能已在满天星成功核销。

## 5. 联调验收

1. 满天星已登录且海卓大脑存在同手机号账号时，打开 H5 直接进入文字对话。刷新后会话仍有效，能访问该账号原有历史。
2. 短时票据过期后重新打开可拿到新票据。并发提交同一票据时，只有一次能建立会话。
3. 同一设备先后用满天星账号 A、B 进入时，分别加载各自的对话。B 的票据兑换失败时停在失败页，刷新失败页也不会恢复 A 的对话。
4. 已核销但手机号未开通时，提示联系管理员，海卓大脑数据库中没有新增账号。
5. 满天星与海卓大脑在联调环境验证 WebView 能接收地址片段、刷新后能恢复 Cookie 会话，并检查访问日志和埋点没有记录票据。

双方确认事项：签发和核销的实际地址、服务间凭证发放方式、票据有效期、手机号格式，以及用于真机联调的入口与测试账号。现有海卓大脑会按手机号识别管理员，双方也需明确管理账号是否允许从满天星入口登录。
